# CRAD-JOS — Diagnostic Services Web Application

A modern, high-performance web platform for **CRAD Diagnostic Services** in Jos, Plateau State, Nigeria. Providing advanced medical imaging and laboratory diagnostics with a cosmic dark-glassmorphism aesthetic.

---

## 🌟 Key Features

- **Diagnostic Care Matrix:** Interactive showcase of 11 medical imaging & laboratory diagnostics:
  - **Medical Imaging:** MRI, CT Scan, Digital Mammography, 4D Ultrasound, Digital X-Ray, X-Ray Imaging, X-Ray Special Procedures.
  - **Laboratory & Clinical Diagnostics:** Clinical Pathology, EEG, ECG, Echocardiogram.
- **Category Filter:** Instant 3-way toggle between *All Services*, *Medical Imaging*, and *Laboratory Diagnostics*.
- **Patient Portal & Inquiry Modal:** Direct modal dialog for procedure inquiries and patient portal access.
- **Facilities & Equipment Showcase:** Highlighting modern imaging suites with live operational status badges.
- **Zero-Token Testing Protocol:** Built-in headless CLI invariant verification runner (`npm test`) outputting compact ASCII audit tables in sub-seconds.
- **Lightweight Architecture:** Zero-dependency vanilla HTML5, CSS3, and ES6+ JS with a custom Node.js static server.

---

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)

### Running Locally
```bash
# Clone the repository
git clone https://github.com/FalconerOne/crad-jos.git
cd crad-jos

# Start the local server
npm start
# or
node server.js
```
The application will be live at `http://localhost:3000`.
